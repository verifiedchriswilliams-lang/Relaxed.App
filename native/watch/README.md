# relaxed — Apple Watch companion (V1)

A **native watchOS (SwiftUI)** breathing companion. Not a web wrapper — watchOS
can't run the Capacitor/Web-Audio app, so this is a genuinely native build that
shares the App Store listing. V1 is standalone and does three things well:

1. **Pick a length** — 1 / 3 / 5 / 10 minutes (Digital Crown).
2. **Haptic breathing pacer** — a breathing orb + a wrist tap on each turn (an
   *up* tap to inhale, a *down* tap to exhale), on the same 6s-in / 2.5s-hold /
   6s-out cadence as the phone. Silent and eyes-free.
3. **Mindful Minutes to Apple Health** — the completed sit is logged.

Plus start / pause / end, a quiet "well done", and a mindfulness extended-runtime
session so it keeps running with the wrist down.

**Not in V1** (later): on-watch AI voice/soundscape (needs an AVAudioEngine
rebuild — v2), and controlling a phone session over WatchConnectivity (v1.1).

The files here are the whole app:

| File | What it is |
|---|---|
| `RelaxedWatchApp.swift` | `@main` App + the 3-screen router (`RootView`) |
| `Views.swift` | `SetupView` (pick length), `SessionView` (orb + controls), `DoneView` |
| `SessionEngine.swift` | The state machine: breath clock, haptics, timer, Health logging |
| `Theme.swift` | Brand colors (Ink/Bone) + the breath cadence (mirrors `lib/breath.ts`) |
| `HealthStore.swift` | HealthKit auth + write Mindful Minutes |
| `ExtendedRuntime.swift` | Mindfulness `WKExtendedRuntimeSession` (keeps it alive) |
| `relaxed-Watch-App-Watch-App-Info.plist` | Tracked reference copy of the watch target's `Info.plist` (restore if it goes missing — see "Keeping the target in sync") |

> As with the StoreKit plugin, `ios/` is generated by `npx cap add ios` and is
> **not** committed, so the watch target + these files must be re-added if you
> regenerate `ios/`. Once the watch target exists, avoid a fresh `cap add ios`.

## 1. Add a watchOS target

```bash
npm run ios:open        # opens ios/App/App.xcworkspace
```

- **File → New → Target… → watchOS → App.** Name it **`relaxed Watch App`**.
  - Interface **SwiftUI**, Language **Swift**, Life Cycle **SwiftUI App**.
  - "Include Notification Scene" / tests: **unchecked**.
  - When asked, **activate** the new scheme.
- Xcode generates a template `…App.swift` and `ContentView.swift` for the watch
  target. **Delete both** (Move to Trash) — ours replace them, and two `@main`
  types won't compile.

## 2. Add these source files

- Drag **all six `.swift` files** from `native/watch/` into the **`relaxed Watch
  App`** group in Xcode. When prompted: **Copy items if needed**, and add them to
  the **`relaxed Watch App` target only** (not the iOS app target).

### Keeping the target in sync

Because the files were added with **Copy items if needed**, Xcode compiles its own
copies under `ios/App/relaxed Watch App Watch App/`, *not* the originals here. So
after pulling any change to `native/watch/*.swift`, re-copy them into the target:

```bash
cd ~/Relaxed.App && git pull origin main && cp native/watch/*.swift "ios/App/relaxed Watch App Watch App/"
```

(The alternative is to re-add the files with "Copy items if needed" **un**checked
so Xcode references `native/watch/` directly and pulls flow through with no copy
step. The copy command above is the low-friction path we use.)

## 3. Capabilities (on the watch target)

Select the **`relaxed Watch App`** target → **Signing & Capabilities**:

- **+ Capability → HealthKit.** (Leave "Clinical Health Records" off.)
- **+ Capability → Background Modes → check "Mindfulness".** This is what lets the
  `WKExtendedRuntimeSession` keep the sit running with the wrist down. (If you
  don't see a Mindfulness checkbox on your Xcode version, add the key manually in
  step 4: `WKBackgroundModes` = array with one item, `mindfulness`.)

## 4. Info.plist (watch target)

Add a HealthKit usage string so the permission prompt has copy (write-only, but
required to save):

- **`NSHealthUpdateUsageDescription`** →
  `relaxed logs your finished sessions to Apple Health as Mindful Minutes.`
- (Optional, harmless) **`NSHealthShareUsageDescription`** → same string. We never
  read Health data; this only appears if the OS asks.

If the Mindfulness capability checkbox wasn't available in step 3, also add:

- **`WKBackgroundModes`** → Array → one String item: `mindfulness`.

### Recovering a lost Info.plist

The watch target uses a **physical** `Info.plist` (build setting `INFOPLIST_FILE`
= `relaxed Watch App Watch App/relaxed-Watch-App-Watch-App-Info.plist`). If it ever
goes missing (a build error like *"Build input file cannot be found: …-Info.plist"*),
restore the tracked reference copy in one command:

```bash
cp "native/watch/relaxed-Watch-App-Watch-App-Info.plist" "ios/App/relaxed Watch App Watch App/"
```

It carries the display name (`relaxed`), the HealthKit usage string, `WKApplication`,
and `WKBackgroundModes` = `mindfulness`. Keep the tracked copy in step with any Info
changes you make in Xcode.

## 5. Deployment target & run

- Set the watch target's **minimum deployment to watchOS 10.0** (or your floor).
- Pick the **`relaxed Watch App`** scheme + a paired **Apple Watch simulator** (or
  your device), and **Run**.
- Expect: the setup screen (crown picks minutes) → **begin** → the orb breathes
  with an up/down haptic each turn and a live countdown → at the end (or **end**),
  a "well done" that says "added to Health", and the sit appears in the Health app
  under **Mindfulness**.

## Notes / gotchas

- **Haptics + Health don't fire in the simulator's earlier builds reliably** — the
  orb + timer will still run, but confirm haptics and the Health write on a real
  paired watch.
- The app is **standalone**: it doesn't need the phone app running. It shares the
  bundle prefix (e.g. `app.relaxed.watchkitapp`); Xcode sets this when you create
  the target.
- If the build complains under **Swift 6 strict concurrency**, set the watch
  target's Swift Language Version to **Swift 5** for now (the engine drives its
  timer on the main run loop by design) — we can revisit strict-concurrency
  annotations later.
- Ship checklist (when V1 is ready): a watch app icon set, then archive the
  combined app; the watch app rides along with the iOS submission.
